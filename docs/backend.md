# 업무 API

Java21 / Spring Boot 3.5 / Spring Security / JPA / Flyway. 세션 로그인, CSRF, 역할별 API, 담당자 소유권을 검증한다. 컨트롤러 경로와 데이터는 contracts.md가 기준이다. 실제 배정 확정 API는 없다.

프로필·요건은 JSONB 복합 값으로 시작하고, 요청·인력·사용자·후보·분석 작업은 별도 관계형 테이블로 둔다. 스키마는 Flyway가 생성하며 AI Worker는 이를 직접 변경하지 않는다.

JSONB 직렬화도 HTTP용 ObjectMapper를 사용해 날짜를 ISO8601 문자열로 통일한다. 분석 결과는 타입이 지정된 JSON 배열로 읽어 브라우저에 이중 JSON 문자열을 보내지 않는다. 요청·가상 인력 snapshot은 같은 트랜잭션에서 작업으로 저장한다. 요청을 잠그고 이미 진행 중인 분석이 있으면 같은 작업을 반환한다.

GET latest-analysis는 마지막 작업을 반환하여 결과 열람만으로 재분석하지 않는다. 결과의 근거는 분석 당시 기록이고, employee 정보는 조회 시 DB에서 갱신한다. 이력 변경에 대한 버전 경고와 대규모 정규화는 후속 작업이다.

로컬 demo seed 계정은 account / manager이며 비밀번호는 환경 변수로만 받는다. 새 운영 계정 등록·초기 관리자 발급 UI, 완전한 감사 로그 적재, 비밀번호 변경 절차는 아직 구현하지 않았다. 이 틀은 운영 보안 검토를 대체하지 않는다.
