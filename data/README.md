# 가상 데이터

employees.json: 실존 인물이 아닌 가상 인력 16명. 이름·이력·배정 일정은 모두 시연용이다.
evaluation_requests.json: 팀이 검토할 초기 정답 세트 10건. 추천 입력만 모델/검색기에 전달하며 expectedIds는 평가기에서만 사용한다.

기술 별칭(MES ↔ 제조실행시스템, Java ↔ 자바), 프로젝트 기술만 가진 PM, 투입/미투입/미확인 상태를 포함한다. ASSIGNED의 assignment는 실제 시연 일정이며 프로젝트 참여 이력의 기간과 구분한다. 2026-11-02 기준으로 만든 예시라 시간이 지나면 현황을 재검토해야 한다.

이 데이터로 측정한 점수는 실제 고객 데이터의 성능을 증명하지 않는다. 정답은 팀의 Account 역할 검토와 별도 보류 평가 세트로 보강해야 한다. 실제 임직원 데이터는 넣지 않는다.
